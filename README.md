# 废墟图书馆动作预览组件

用于 LibRModMaker 动作选择器的可选外置 GIF 包。

## 1.4.1

修正姿势筛选导致的漏图；为全部已有预览统一角色原点和比例，避免每帧单独放大居中。《一点突破》依据脚本顺序补上前冲/后撤的参考位移与时长。此前已对照本机 Steam PC 游戏代码整理189个动作条目的预览：互斥分支、交替动作和不同目标的动作分别展示，排除对手姿势，纠正默认姿势映射及变身外观关联。单颗骰子实际包含的连段保留。

GIF高1024像素，无文字覆盖。使用本机原版角色姿势；《一点突破》含参考位移，其余为姿势预览，未复现粒子与实战镜头。预览可按当前骰子姿势或序号自动匹配，状态或随机分支可在制作器中点击小图切换。

## 下载

在 [Releases](https://github.com/goldotto/lor-action-previews/releases/tag/v1.4.1) 选择 E.G.O、来宾或异想体组件，或在制作器的“预览组件”下载。地址指向 GitHub Releases，部分网络可能无法连接。

鼠标停留条目时显示小 GIF，悬停小 GIF 时放大。组件可独立移除，预览可关闭。

## 自制 GIF

点击动作条目右侧的小图或导入按钮，为当前模组的该动作导入 GIF；对应关系保存在本机。

## 索引和来源

`index.json` 记录每个独立分支的姿势、外观、代码依据、适用骰子和组件下载地址。ZIP只包含生成的GIF与来源记录；不包含游戏程序集、原始图集或用户模组。

原始美术属于 Project Moon。来源为本机 Library of Ruina Steam PC，核对日期2026-10-21。
