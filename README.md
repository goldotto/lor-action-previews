# 废墟图书馆动作预览组件

用于 LibRModMaker 动作选择器的可选外置 GIF 包。

## 1.4.2

补齐原版书页使用的50个漏图脚本，新增70个预览，累计239个脚本、332个GIF。单姿势也可显示，哭泣之子从另一类原生资源补齐；修正运行时加卡、召唤物、变身阶段关联。静默少女终段按五颗骰子分别展示，白夜忏悔不混入受击者姿势。

保留1.4.1对《恍惚的终局》的筛选修复和《一点突破》两骰独立位移参考。每张图取一个骰子或状态路径，不把互斥动作或多颗骰子拼接；同一骰子自身的合法多阶段动作保留。

GIF高1024像素，无文字覆盖，来自本机原版角色姿势。单姿势可以是静态GIF；它们是动作姿势参考，不是完整粒子和实战镜头录像。17个类尚无直接原版XML骰子关联，未以猜测的人物补图。

## 下载与使用

在[Releases](https://github.com/goldotto/lor-action-previews/releases/tag/v1.4.2)选择E.G.O、来宾或异想体组件，或从制作器下载。链接指向GitHub Releases，部分网络可能无法连接。

鼠标停留条目显示小图，悬停小图放大。组件可关闭、独立移除。点击小图可切换分支，或为当前模组的动作导入自制GIF。
